# XAG

> XAG is a Guangzhou-based agricultural technology company building autonomous farming solutions — agricultural drones (P150 Max, P150, P100 Pro, P60), R100/R200 agricultural ground rovers, the APC2 AutoPilot console, and smart-farm IoT devices (FBV, FPI, FC5, FS2, FR2). Backed by SoftBank Vision Fund. XAG operates a Chinese-language developer Open Platform (open.xa.com) integrating application management, device data authorization, secure data communication, and message subscription, exposing APIs for building on XAG device and operations data; most public API documentation is not yet published.
